## 参考答案

### 1. 图形渲染管线

管线大框架:顶点数据 → 顶点着色器(MVP变换) → 图元装配 → 几何着色器(可选) → 裁剪/屏幕映射 → 光栅化(生成片元+属性插值) → 片元着色器(着色/纹理采样) → 各类测试与混合(裁剪、深度/模板测试、混合) → 帧缓冲输出。

#### 1.1 DrawCall 是什么,为什么要减少

- DrawCall 是 CPU 通过图形 API(如 glDrawArrays / DrawIndexed)向 GPU 提交的一次绘制命令,本质是把"某个状态(绑定哪些 VAO/材质/Shader)+ 一批图元"的渲染请求推入命令队列,由 GPU 异步执行。
- 单次 DrawCall 的 GPU 开销不大,昂贵的是 **CPU 侧开销**:API 调用进入驱动的验证、状态切换、命令缓冲填充;DrawCall 数量太多时 CPU 提交成为瓶颈,GPU 反而空闲( poorer parallelism )。
- 减少手段:合并几何(静态合批)、GPU Instancing(同一网格多实例一次画完)、纹理图集/数组减少状态切换、减少多余材质变体、多线程提交/Vulkan 式低开销 API、GPU Driven Rendering(剔除与绘制都放到 GPU)。

#### 1.2 粗细粒度 Culling 的区别

- **粗粒度**:以"整个物体/实例"为单位,通常在 CPU 上做,剔除后整批几何不进入管线。典型:视锥体剔除(包围盒测试)、遮挡剔除(Hierarchical Z / Occlusion Query / PVS)、小对象剔除、入口剔除。
- **细粒度**:以"三角形/片元/像素块(tile)"为单位,通常由 GPU 硬件或 GPU 上的 pass 完成。典型:背面剔除、视口裁剪、scissor、Early-Z/Hi-Z、Tile-Based Culling(Forward+/延迟渲染的 tile 光源列表)。
- 区别总结:粗粒度剔除"整批提交",省 DrawCall/CPU/带宽;细粒度剔除"逐图元逐像素",省着色与带宽。二者互补:先粗后细。

#### 1.3 MVP、Viewport 变换

- **Model**:物体局部坐标 → 世界坐标(平移/旋转/缩放,法线用逆转置矩阵)。
- **View**:世界坐标 → 观察相机空间(相机的逆变换)。
- **Projection**:观察空间 → 裁剪空间(clip space)。透视投影把视锥体压成长方体,并给 w 赋值用于透视除法与深度非线性化;输出 gl_Position 处于裁剪空间,还要经过图元裁剪(±w)。
- **透视除法**:(x,y,z)/w → NDC 归一化设备坐标(范围 [-1,3]^3 内 [-1,1])。
- **Viewport 变换**:NDC → 屏幕像素坐标(glViewport 定义的窗口矩形 + glDepthRange 的深度范围)。它只做线性缩放/平移,不涉及透视。

#### 1.4 深度测试与 Early-Z

- **深度测试**:光栅化输出每个片元携带深度值,与深度缓冲中已有值比较(GL_LESS/GL_LEQUAL 等),通过才写入颜色(并按需更新深度),解决"谁遮挡谁"。
- **Early-Z**:现代 GPU 在光栅化之后、片元着色器之前先做深度测试,被遮挡的片元直接丢弃,省掉昂贵的 FS 执行(纹理采样、光照计算)。
- 失效条件:FS 中 discard、修改深度(gl_FragDepth)、alpha test 等副作用 → 硬件回退到保守策略或禁用 Early-Z。这也是"延迟渲染在 G-buffer pass 前必须先写深度""透明物体放最后画"的原因。

#### 1.5 延迟渲染

- 流程:① Geometry Pass:渲染场景到 G-Buffer(MRT:Position/Normal/Albedo/Roughness-Metallic + 深度);② Lighting Pass:全屏 quad,逐像素从 G-Buffer 取数据,屏幕空间对每个光源计算着色;③ 后处理与输出。
- **优点**:光源数量增长时成本 ≈ O(像素 × 光源),与场景几何复杂度无关;每个像素只被着色一次,天然消灭 overdraw 的着色浪费;材质计算只在最终 pass 进行一次。
- **缺点**:
  - G-Buffer 显存与带宽开销大(多个 RT,分辨率相关);
  - 不支持硬件 MSAA(见 2.2);
  - 不支持半透明(透明物体必须额外的前向 pass);
  - 材质变体受限(G-Buffer 布局固定,不同 shader 模型难混用);
  - 需要 MRT 与足够带宽的硬件。
- 演进:Forward+(分块光源列表的前向)、Clustered Rendering 兼顾两者优点。

#### 1.6 半透明物体渲染顺序

1. 先渲染所有**不透明**物体(开深度写入+深度测试,排序无关紧要,深度测试保证正确)。
2. 关闭深度**写入**(但保留深度**测试**),开启混合(GL_BLEND)。
3. 半透明物体按**相机距离从远到近**排序渲染——混合运算不满足交换律,先后顺序影响结果。
- 逐像素级无法完全解决排序,标准做法就是按物体排序;更高级方案:深度剥离(depth peeling)、A-Buffer / per-pixel linked lists、顺序无关透明(OIT)、预乘 alpha。
- 透明物体内部也要注意:同一物体两个面也需排序,常见做法按三角形中心排序或直接接受误差。

#### 1.7 Shader 中为什么避免 if

- GPU 是 SIMT/SIMD 执行:一个 warp/subgroup 内的线程按同一指令步调执行。
- **Divergent 分支**(不同线程走了不同路径)会导致两个分支都被执行再各自屏蔽无效线程,实际耗时 ≈ 两个分支之和,还有寄存器/调度负担。
- **Uniform 分支**(整个 drawcall 同一值,如 u_UseFog)代价很小,可以放心用。
- 片元着色器里逐像素条件(如 if (brightness > 1.0))是典型发散分支,应改用 mix/smoothstep/step、min/max 等无分支写法。
- 另外:分支会妨碍编译器展开循环、影响寄存器分配导致 occupancy 下降;有的分支(纹理采样副作用)还会影响 Early-Z 与衍生度计算(texture grad)。

### 2. 抗锯齿技术

#### 2.1 MSAA 与 SSAA 的区别

- **SSAA(超采样)**:渲染到 N 倍分辨率的目标,再把 N 个像素降采样成 1 个。所有像素(包括内部)都被超采样,抗锯齿最彻底(也抗着色锯齿),但着色/带宽开销是 N 倍,代价最大。
- **MSAA(多重采样)**:硬件层面,每个像素放 N 个采样点,只对**图元边缘**判断覆盖率;每像素只运行**一次**片元着色器(结果共享给被覆盖的采样点),颜色/深度/模板缓冲按采样点存储。只平滑几何边缘锯齿,不处理纹理/着色锯齿(那些靠 mipmap/各向异性过滤),开销远小于 SSAA。
- 核心差异:SSAA 在"分辨率维度"整体加密;MSAA 只在"覆盖采样"维度加密,并且着色不翻倍。

#### 2.2 延迟渲染为什么用不了硬件 MSAA

- MSAA 的机制是:同一图元的多重采样共享一次 FS 结果,G-Buffer pass 时每个采样点都要存各自的 Normal/Position/材质数据才能在 Lighting Pass 正确复原边缘归属。
- 但 **Lighting Pass 是逐像素而非逐采样点**执行的,它已经无法知道某像素边缘内的多个采样点分别属于哪个图元(几何信息在 G-Buffer 里已经"聚合"丢失),即便用多重采样 G-Buffer 也会带来 N 倍带宽,与延迟渲染省带宽的初衷矛盾。
- 工程上的替代:对 G-Buffer 做边缘检测后用后处理 AA(SMAA/TAA)、分块前向(Forward+)、或对延迟管线做"重新解析"(如 AMD 的 RTA/MSAA 复原)。

#### 2.3 DLSS 原理简述

- 本质:**时间性超分辨率**。输入低分辨率渲染帧 + 深度 + 运动矢量(Motion Vector),输出高分辨率帧。
- 流程:低分辨率渲染时对相机做 jitter(子像素抖动);通过运动矢量把历史帧信息重投影到当前帧,与当前帧做加权融合累积(类似 TAA 的思想);神经网络(卷积/后期用张量核)利用这些时序+空间特征重建细节、还原被抖动的像素;最后做防鬼影校验与锐化输出。
- DLSS 3 额外引入"帧生成"(用光流 + 神经网络在两帧之间插出全新帧),属于另一个层次的技术。核心思想:用"时间累积 + 学习到的先验"以远低于原生渲染的代价逼近高分辨率质量。

### 3. 光照模型

#### 3.1 BRDF 概念

- **BRDF**(Bidirectional Reflectance Distribution Function) f(l, v):描述从入射方向 l 射来的光,被表面反射到出射方向 v 的比例,单位 1/sr。
- 性质:能量守恒(总反射能量 ≤ 入射)、亥姆霍兹互易性(f(l,v)=f(v,l))。
- 渲染方程中对半球所有入射方向积分 BRDF × 入射辐照 × cosθ 得到出射辐亮度,是现代 PBR 的数学核心。

#### 3.2 Blinn-Phong 模型

- 经验模型,三部分相加:
  - **Ambient(环境光)**:ka × 全局环境光,模拟间接光的近似;
  - **Diffuse(漫反射)**:kd × (N·L) × 光颜色,兰伯特余弦定律,与观察方向无关;
  - **Specular(高光)**:ks × (N·H)^shininess,引入半程向量 H = normalize(L+V) 代替反射向量,计算比 Phong 便宜,高光形状由 shininess 控制。
- 局限:各项系数手工设定、不保证能量守恒、没有菲涅尔现象与微表面理论,只能算"看起来像",不是物理正确。

#### 3.3 PBR 模型(Lambert 漫反射 + Cook-Torrance 镜面反射)

- **漫反射**:Lambert —— albedo/π × (N·L),除以 π 保证单位半球内能量守恒。
- **镜面反射**:Cook-Torrance BRDF:D·F·G / [4 × (N·V) × (N·L)]
  - **D(Normal Distribution Function)**:法线分布函数,常用 GGX/Trowbridge-Reitz。描述微表面法线与半程向量 H 对齐的统计密度,由 roughness 控制 —— roughness 越小高光越锐利;
  - **F(Fresnel)**:菲涅尔项,常用 Schlick 近似 F0 + (1-F0)(1-V·H)^5。描述视角越掠射反射越强;F0 是垂直入射的基础反射率(非金属约 0.04,金属用 albedo);它同时决定 specular 权重 kS,进而 kD = (1-kS)(1-metallic),实现漫反射/镜面的能量守恒;
  - **G(Geometry)**:几何遮蔽/阴影项,常用 Smith-Schlick-GGX。描述微表面之间互相遮挡导致的光衰减,roughness 越大遮挡越强。
- 整体特点:参数直观且物理可测(albedo、metallic、roughness、F0),满足能量守恒与互易性,在不同光照环境下表现一致。
